ws keeps your second brain in one folder: your projects, tasks, documents,
papers, contacts, events and career facts, as small plain records with explicit
relations between them, such as a paper's authors or a document's project.
People and agents use the same commands. When an agent starts a session inside
the workspace, ws briefs it: where it is, the house rules there, what has
happened. Setup takes a few minutes, and its first objects are about you, so
that every agent knows whose workspace this is.
