You are helping a person set up ws. Tell them what this step says, in your
own words. Ask the questions and wait for their answers. Run the command with
those answers, then run `ws setup` again for the next step. Ask for facts;
never fill them in from what you think you know. What they skip stays empty
and can be added later. If you are that person, at a terminal, answer the
questions yourself and run the command.

What ws is, to tell them once, unless you already have:

    ws keeps a person's second brain in one folder: their projects, tasks,
    documents, papers, contacts, events and career facts, as small plain
    records with explicit relations between them, such as a paper's authors
    or a document's project. People and agents use the same commands. When
    an agent starts a session inside the workspace, ws briefs it: where it
    is, the house rules there, what has happened. Setup takes a few minutes,
    and its first objects are about the person, so that every agent knows
    whose workspace this is.
