A project is a piece of work with a folder of its own: code, data, a paper, slides,
and a log of what happened. Agents working there read its purpose and its log.

Projects are sorted by type and by fields, which become browse folders later. The
types so far are {project_types}. The broad fields so far are {fields}, and papers
share them. Add yours, with the subfields you would want to find things by.

If you have something on the go, name it and it becomes your first project.
