A document is one file worth addressing on its own: an invoice, a contract, a
certificate, a slide deck. A bundle of files that only matter together is a resource
instead, and a paper is literature, even as a loose PDF.

Documents are sorted by type, and the types so far are {document_types}. Add any you
know you will need; new ones can also be added when you first file one.

If a file comes to mind, give its path and setup files a copy, leaving the original
where it is.
